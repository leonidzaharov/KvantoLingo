# Учебный контент

## Два способа работы

Основной способ — административный редактор в `/admin/lessons`. Он сохраняет
контент сразу в PostgreSQL и подходит для ежедневной работы наставника.

`prisma/seed-lessons/` — переносимый стартовый набор для развёртывания новой
среды. Seed не является источником истины production-базы и может очищать
каталог перед загрузкой.

## Структура seed-каталога

Каждый подкаталог представляет курс:

```text
prisma/seed-lessons/
  scratch/
    category.json
    01-vvedenie.json
    02-dvizhenie.json
```

`category.json` задаёт название и иконку. Остальные JSON-файлы сортируются по
имени и содержат уроки. Точный формат и runtime-валидация определены в
`prisma/seed.ts` и `src/lib/lesson-content.ts`.

Перед изменением формата сначала обновите валидатор и тесты, затем редактор и
seed. Не добавляйте поле только в UI: старый контент должен либо пройти
валидацию, либо получить явную миграцию.

## Типы блоков

### Теория

Markdown отображается через безопасный общий компонент. Используйте короткие
абзацы, примеры и один новый термин за раз. Изображения загружайте через
административный редактор.

### Вопрос с вариантами

Нужны формулировка, варианты и индекс правильного ответа. Не используйте
варианты вроде «всё перечисленное», если можно проверить конкретное знание.

### Кодовое задание

Поддерживаются Python и JavaScript. Проверяется вывод программы, а не буквальное
совпадение исходного кода. Поэтому допустимы разные корректные решения.

Хорошее задание:

- имеет детерминированный ожидаемый вывод;
- выполняется быстро и без сети;
- не требует файловой системы;
- содержит достаточно контекста в условии;
- проверяет один навык.

## Публикация урока

Новый курс и урок всегда создаются черновиками. Безопасный процесс:

1. создать и сохранить урок;
2. открыть «Предпросмотр от лица ученика»;
3. исправить формулировки и награды;
4. выбрать аудиторию урока;
5. вручную опубликовать его в нужный момент занятия.

Снятие с публикации не удаляет прогресс. Копия урока или курса всегда создаётся
черновиком.

## Seed и рабочие данные

Обычный запуск:

```bash
npx tsx prisma/seed.ts
```

PowerShell:

```powershell
npx.cmd tsx prisma/seed.ts
```

Если в базе уже есть прогресс, seed остановится. Принудительный режим очищает
каталог и требует осознанного подтверждения через окружение:

Git Bash:

```bash
export SEED_FORCE=1
npx tsx prisma/seed.ts
unset SEED_FORCE
```

PowerShell:

```powershell
$env:SEED_FORCE='1'
npx.cmd tsx prisma/seed.ts
Remove-Item Env:SEED_FORCE
```

Не запускайте принудительный seed в production как способ обновить один урок.
Для production используйте админку или отдельную контролируемую миграцию данных.

## Чек-лист качества курса

- курс соответствует направлению группы;
- уроки идут от простого к сложному;
- каждый новый навык используется повторно;
- кодовые задания проверяют результат, а не копирование образца;
- награды не позволяют бесконечное повторное начисление;
- курс пройден целиком тестовым профилем;
- сложные места подтверждены наблюдением на занятии.
